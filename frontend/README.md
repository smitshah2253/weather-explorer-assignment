# Weather Explorer Frontend

This is a React 19 Single Page Application (SPA) built with Vite and TypeScript. It forms the frontend for the Weather Explorer monorepo.

## Tech Stack
- **Framework**: React 19 (via Vite)
- **Styling**: Tailwind CSS v4, shadcn/ui
- **State/Data**: TanStack Query
- **Routing**: React Router
- **Forms**: React Hook Form, Zod
- **Icons**: Lucide React
- **Data Viz**: Recharts

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

## Folder Structure
- `src/` - Application source code.
  - `App.tsx` - Root component.
  - `main.tsx` - Entry point.
  - `index.css` - Global CSS and Tailwind definitions.
- `public/` - Static assets.
- `vite.config.ts` - Vite configuration.
- `package.json` - Dependencies and scripts.
